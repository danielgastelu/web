¿Cómo funciona esto? (Caja Blanca)

El Acelerómetro: Mide la aceleración gravitacional en 3 ejes (X, Y, Z). Cuando tu celular está apoyado sobre una mesa con la pantalla hacia arriba, los grados de inclinación (Beta y Gamma) son cercanos a 0. El algoritmo lee estos datos y usa un bloque condicional (if) para habilitar el sonido solo si el móvil está horizontal.

El Sensor de Luz Ambiental: Es un fotodiodo que genera una pequeña corriente eléctrica al recibir fotones. En el modo "Tiempo Real", usamos la AmbientLightSensor API para medir los Lux. Si el navegador restringe este sensor por privacidad, el sistema utiliza un modelo matemático que calcula la luz teórica según la hora del eclipse.

El Sonido y las Matemáticas: No usamos archivos MP3. Usamos la Web Audio API para generar ondas matemáticas. La cantidad de luz se multiplica por una frecuencia base. A mayor luz (fuera del eclipse), mayor frecuencia (sonidos agudos). Durante el máximo del eclipse, la luz cae, reduciendo la frecuencia (sonidos graves). Para que suene agradable, el algoritmo selecciona aleatoriamente notas de una escala pentatónica, garantizando armonía matemática.
